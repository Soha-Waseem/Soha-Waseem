## Projects
 
### Autocorrect Pro
A two-stage NLP text correction system — pairing a custom Damerau–Levenshtein edit-distance spell corrector with a T5 Transformer for grammar correction. Includes a hallucination guard to keep model outputs reliable, deployed through a Streamlit interface across a six-module architecture.
 
### Plastic Object Classifier
A CNN trained to classify plastic objects into three categories, reaching **99.5% accuracy** in 15 training epochs — built for real-world waste-sorting applications.
 
### Spam Email Detector
A Logistic Regression classifier for spam detection, reaching **96% validation** and **94% test accuracy**, evaluated using precision, recall, and F1-score.
 
### Printer Job Scheduler
A priority-based job scheduler written in C++, featuring persistent storage, queue management, and performance tracking.
