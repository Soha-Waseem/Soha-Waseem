## Projects

### Autocorrect Pro
I built this to fix a problem I kept running into with off-the-shelf spell checkers: they either miss context-based errors or overcorrect things that were already fine. It runs in two stages — a custom Damerau–Levenshtein spell corrector catches typos, then a T5 Transformer handles grammar. I also added a hallucination guard so the model doesn't "fix" text into something that changes its meaning. Wrapped it all in a Streamlit app across six modules so it's actually usable, not just a script.

### Plastic Object Classifier
A CNN that sorts plastic objects into three categories, built with recycling/waste-sorting use cases in mind. It hit **99.5% accuracy** after 15 epochs of training.

### Spam Email Detector
A Logistic Regression model for catching spam emails. Rather than just chasing a high accuracy number, I evaluated it properly with precision, recall, and F1-score — it landed at **96% validation** and **94% test accuracy**.

### Printer Job Scheduler
A C++ scheduler that manages print jobs by priority, with persistent storage so nothing's lost on restart, plus queue management and performance tracking built in.

You can find the full code for each of these in my pinned repositories.
